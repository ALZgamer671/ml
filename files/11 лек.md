# Лекция 11. Обучение без учителя — кратко

## Отличие от обучения с учителем

Нет целевой переменной — нужно найти скрытую структуру в данных. Качество решения формально оценить сложно ("сохранить основные закономерности" плохо формализуется).

## 1. Кластеризация

Цель: разбить объекты на `K` групп так, что внутри группы объекты похожи, а между группами — нет: `a: X → {1,...,K}`.

### Метрики качества

**Внутренние** (без знания истинных меток):
- **Внутрикластерное расстояние** (минимизировать): `ΣΣ [a(xᵢ)=k]·ρ(xᵢ,cₖ)` — сумма расстояний объектов до центра своего кластера
- **Межкластерное расстояние** (максимизировать): сумма расстояний между объектами разных кластеров
- **Индекс Данна:** `min(расстояние между кластерами) / max(внутрикластерное расстояние)` — максимизировать

**Внешние** (если известны истинные кластеры) — можно применять обычные метрики многоклассовой классификации (F-мера с микро/макро усреднением), рассматривая кластеризацию как классификацию.

### K-Means

Оптимизирует внутрикластерное расстояние с квадратом евклидовой метрики. Две степени свободы: центры кластеров `cₖ` и распределение объектов `a(xᵢ)` — оптимизируются **по очереди** (алгоритм ЕМ-типа):
1. Зафиксировать центры → каждый объект относим к ближайшему центру: `a(xᵢ)=argmin ρ(xᵢ,cₖ)`
2. Зафиксировать распределение → центр = среднее объектов своего кластера: `cₖ = среднее xᵢ, где a(xᵢ)=k`
3. Повторять до сходимости

**Минус:** сильно зависит от начального приближения центров → нужна умная инициализация (напр. **k-means++**).

### Графовые методы

Строим граф близости (ребро между объектами, если расстояние < порога), кластер = компонента связности графа. Просты, но при хорошей метрике расстояния работают неплохо.

### Иерархическая кластеризация

Строит иерархию, а не плоское разбиение. **Восходящий подход (agglomerative):** начинаем с ℓ кластеров-синглтонов, на каждом шаге объединяем два самых похожих кластера (по функции `d(Xₘ,Xₙ)`, напр. расстояние между центрами), пока не останется один кластер.

## 2. Визуализация (снижение размерности до 2D/3D с сохранением структуры)

### Многомерное шкалирование (MDS)
Ищем проекции `zᵢ`, минимизируя расхождение попарных расстояний:
```
Σ (ρ(xᵢ,xⱼ) - ρ(zᵢ,zⱼ))² → min
```
Плюс: объекты не обязаны быть векторами — нужна лишь функция расстояния между ними (можно визуализировать хоть строки). Минус: нет параметрической связи между старым и новым пространством → нельзя легко спроецировать новый объект без пересчёта всей задачи.

### t-SNE — популярнее MDS, решает его проблемы

Идея: важны не точные расстояния, а **пропорции** близости.

1. В исходном пространстве близость через нормальное распределение → превращаем в условные вероятности `p(i|j)`, затем **симметризуем**: `pᵢⱼ = (p(i|j)+p(j|i))/(2ℓ)`
2. В новом (низкоразмерном) пространстве используют **распределение Коши** (тяжёлые хвосты — не так сильно штрафует за увеличение расстояний, что важно, поскольку в высокой размерности можно уместить объекты гораздо "теснее", чем в 2D)
3. Минимизируем **дивергенцию Кульбака-Лейблера** между распределениями `p` и `q`:
```
KL(p‖q) = Σ pᵢⱼ·log(pᵢⱼ/qᵢⱼ) → min
```
Решается стохастическим градиентным спуском.

## 3. Обучение представлений (representation learning)

Цель: построить числовые векторы объектов, сохраняющие важные свойства (например, эмбеддинги слов).

### word2vec

**Дистрибутивная гипотеза:** слова, встречающиеся в похожих контекстах, близки по смыслу.

Для каждого слова `w` ищем вектор `w⃗ ∈ Rᵈ`. Контекст слова — соседние слова в пределах окна `K`. Вероятность встретить слово `wᵢ` в контексте `wⱼ` моделируется через **softmax** от скалярного произведения векторов:
```
p(wᵢ|wⱼ) = exp(⟨w⃗ᵢ,w⃗ⱼ⟩) / Σ_w exp(⟨w⃗,w⃗ⱼ⟩)
```
Максимизируем правдоподобие по всем словам и их контекстам во всей выборке текстов (стохастический градиентный спуск). Результат: близкие по смыслу слова получают близкие векторы — знаменитое свойство word2vec (напр. `king - man + woman ≈ queen`).
