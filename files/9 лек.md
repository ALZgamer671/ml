# Лекция 9. Градиентный бустинг — кратко

## Идея

В отличие от бэггинга (независимые модели), бустинг строит модели **последовательно**: каждая следующая исправляет ошибки предыдущих. Итоговый алгоритм — сумма базовых ("слабых") моделей:
```
a_N(x) = Σ γₙ·bₙ(x)
```

## Простая интуиция (регрессия, MSE)

1. Обучаем `b1(x)` на исходные ответы `y`
2. Считаем остатки: `s_i = y_i - b1(x_i)`
3. Обучаем `b2(x)` приближать остатки `s_i` (не исходные y!)
4. Повторяем: каждый новый алгоритм учится на остатках `s_i = y_i - a_{N-1}(x_i)`, где `a_{N-1}` — уже построенная композиция

## Обобщение: остатки = антиградиент

Для MSE остаток `y-a(x)` оказывается ровно **антиградиентом** функции потерь по предсказанию:
```
s_i = -∂L/∂z |_{z=a_{N-1}(x_i)}
```
Это верно для **любой дифференцируемой** функции потерь, не только MSE! Общий алгоритм градиентного бустинга:
1. Считаем антиградиент `sᵢ` функции потерь L в текущей точке предсказаний
2. Обучаем новый базовый алгоритм `bₙ(x)` приближать `sᵢ` (обычно через MSE — как задачу регрессии на вектор `s`, независимо от того, какая исходная функция потерь L)
3. Подбираем коэффициент `γₙ = argmin Σ L(yᵢ, a_{N-1}(xᵢ) + γ·bₙ(xᵢ))`
4. `a_N = a_{N-1} + γₙ·bₙ`

Это буквально **градиентный спуск**, только в пространстве прогнозов на обучающей выборке (ℓ-мерном), а не в пространстве параметров модели — шаг делается вдоль направления, которое приближает базовый алгоритм.

**Начальная модель `b0`:** простая константа — 0, самый частый класс (классификация), или среднее значение y (регрессия).

## Регуляризация (борьба с переобучением)

**Сокращение шага (learning rate):**
```
a_N(x) = a_{N-1}(x) + η·γ_N·b_N(x),  η ∈ (0,1]
```
Чем меньше `η`, тем обычно лучше итоговое качество (но нужно больше итераций). Число итераций подбирают по отложенной выборке/CV — ошибка на обучении монотонно падает, а на контроле после некоторого момента начинает расти.

**Стохастический градиентный бустинг:** каждый базовый алгоритм обучают не на всей выборке, а на случайном подмножестве (рекомендация — половина исходной выборки). Понижает шум и ускоряет вычисления.

## Функции потерь

- **Регрессия:** MSE (как в базовом варианте) или MAE — антиградиент `sᵢ = -sign(a(xᵢ)-yᵢ)`
- **Классификация:** логистическая функция потерь `L=log(1+e⁻ʸᶻ)` — привычная нам по логрегрессии

## Бустинг именно над деревьями

Дерево = сумма индикаторов по листьям: `bₙ(x) = Σⱼ bₙⱼ·[x∈Rⱼ]`. Так как листья не пересекаются, можно **отдельно подобрать оптимальный коэффициент в каждом листе** (а не один общий `γₙ` на всё дерево):
```
γ_Nj = argmin Σ_{x∈Rj} L(yᵢ, a_{N-1}(xᵢ)+γ)
```
Для MSE/MAE есть аналитическая формула, для логистических потерь — приближение через один шаг метода Ньютона.

## Bias-variance: бустинг vs случайный лес

- **Случайный лес:** базовые деревья — глубокие (низкое смещение), разброс убирается усреднением → нужны глубокие деревья
- **Бустинг:** каждый шаг целенаправленно уменьшает ошибку, поэтому даже простые базовые модели дают сложную композицию → бустинг **снижает смещение**, но не снижает (может даже увеличить) разброс → чтобы не переобучиться, используют **неглубокие** деревья (3-6 уровней, высокое смещение по отдельности, зато меньше риск разброса)

## Взвешивание объектов (AdaBoost и общий случай)

Для экспоненциальной функции потерь `L=e⁻ʸᶻ` (AdaBoost) антиградиент раскладывается как ответ × вес:
```
sᵢ = yᵢ·exp(-yᵢ·a_{N-1}(xᵢ)) = yᵢ·wᵢ
```
- Если объект имеет большой **отрицательный** отступ (типичный шум/выброс) → вес неограниченно растёт → AdaBoost чрезмерно фокусируется на шумовых объектах → неустойчив к шуму

Для **логистической** функции потерь вес ограничен сверху единицей:
```
wᵢ = 1/(1+exp(yᵢ·a_{N-1}(xᵢ)))
```
Шумовой объект получает вес ≈1, а неуверенно классифицированный (полезный для обучения) — вес ≈0.5 — разница всего в 2 раза, гораздо устойчивее к шуму, чем экспоненциальная потеря.

## Методы второго порядка (доп. материал)

Вместо обычного градиента можно использовать **метод Ньютона**, учитывающий вторую производную (матрицу Гессе `H`):
```
s = -H⁻¹g
```
Так как функционал — сумма ошибок по отдельным объектам, `H` — диагональная матрица → сводится к покомпонентному масштабированию антиградиента. На этом основан **LogitBoost**. Похожий эффект даёт и обычный трюк **переподбора значений в листьях дерева** после его построения — сдвиги подбираются индивидуально для групп объектов (листьев), что близко по духу к учёту вторых производных.
