# Лекция 10. XGBoost и стекинг — кратко

## 1. XGBoost — обоснование через разложение Тейлора

Обычный градиентный бустинг обучает базовый алгоритм на антиградиенте (по сути, аппроксимация первого порядка). XGBoost использует разложение функции потерь **до второго члена** ряда Тейлора:
```
Σ L(yᵢ, a_{N-1}(xᵢ)+b(xᵢ)) ≈ Σ [ L(yᵢ,a_{N-1}(xᵢ)) - sᵢb(xᵢ) + (1/2)hᵢb²(xᵢ) ]
```
где `sᵢ` — антиградиент (первая производная, как раньше), `hᵢ` — **вторая производная** (кривизна функции потерь). Первое слагаемое от `b` не зависит — выбрасываем.

**Связь с обычным бустингом:** если раскрыть MSE-функционал `Σ(b(xᵢ)-sᵢ)²`, он с точностью до константы совпадает с формулой выше при `hᵢ=1` — то есть обычный бустинг молчаливо предполагает одинаковую "кривизну" по всем направлениям, а XGBoost использует настоящую `hᵢ`, что точнее.

## 2. Регуляризация дерева в XGBoost

Сложность дерева `b(x)=Σbⱼ[x∈Rⱼ]` определяется:
1. Числом листьев `J`
2. Нормой коэффициентов в листьях `‖b‖² = Σbⱼ²`

Добавляем оба штрафа в функционал:
```
Σ[-sᵢb(xᵢ) + (1/2)hᵢb²(xᵢ)] + γJ + (λ/2)Σbⱼ² → min
```
Поскольку дерево даёт одинаковый ответ на всём листе, задача распадается на независимые подзадачи по листьям. Обозначив `Sⱼ=Σᵢ∈Rⱼsᵢ`, `Hⱼ=Σᵢ∈Rⱼhᵢ`, получаем **аналитическое решение**:
```
bⱼ* = Sⱼ / (Hⱼ+λ)
```
И минимальное значение ошибки дерева (с оптимальными листьями):
```
H(b) = -(1/2)Σⱼ Sⱼ²/(Hⱼ+λ) + γJ
```

## 3. Построение дерева в XGBoost

Формула `H(b)` идеально годится как **критерий информативности** для выбора разбиений:
```
Q = H(R) - H(Rℓ) - H(Rr) → максимизировать
```
Критерий останова: объявить вершину листом, если даже лучшее возможное разбиение даёт `Q<0` (разбиение не окупает штраф за лишний лист `γ`).

**Итог, чем XGBoost отличается от "классического" бустинга:**
1. Направление шага учитывает вторые производные (точнее приближает оптимум)
2. Регуляризация: штраф за число листьев + за норму весов в листьях
3. Критерий информативности дерева зависит от оптимального сдвига (`S`,`H`), а не от произвольного функционала типа MSE
4. Критерий останова дерева тоже завязан на этот оптимальный сдвиг

## 4. Стекинг (Stacking)

Идея: прогнозы нескольких базовых алгоритмов `b₁(x)...bₙ(x)` становятся **новыми признаками**, поверх которых обучается мета-алгоритм `a(x)`.

**Опасность:** если обучать базовые алгоритмы и мета-алгоритм на одной и той же выборке — мета-алгоритм начнёт доверять переобученным базовым моделям (они лучше всего "предсказывают" на своей же обучающей выборке) → катастрофическое переобучение.

**Решение — как в счётчиках, разбиение по блокам (аналог кросс-валидации):**
Выборку делят на K блоков; для объектов блока `k` используются прогнозы базовых алгоритмов, обученных на **всех остальных** блоках (`b⁻ᵏ`). Так мета-алгоритм видит только честные, "внетренировочные" прогнозы.

### Блендинг
Частный случай стекинга — мета-алгоритм линейный:
```
a(x) = Σ wₙ·bₙ(x)
```
Даже без обучения весов (просто среднее, `wₙ=1/N`) блендинг часто улучшает качество по сравнению с отдельными базовыми моделями.

### Категориальные/текстовые признаки в композициях деревьев
Прямая бинаризация (one-hot) категориальных признаков и TF-IDF для текста создают огромную размерность — случайный лес будет медленным (деревья глубокие), а бустинг с неглубокими деревьями (обычно 3-6 уровней) не сможет уловить сложные зависимости от большого числа таких признаков разом.

**Решение:** стекинг — схлопнуть каждый категориальный/текстовый признак в одно число через отдельную базовую модель (напр., счётчики для категорий, линейная модель для текста), а поверх обучить бустинг как мета-алгоритм. Не забываем про честное разбиение выборки для избежания утечки (как для обычных счётчиков).
