# Лекция 1. Введение в машинное обучение — кратко

## Идея

ML применяют там, где нельзя вывести точную формулу из понимания природы процесса (в отличие от физики), но есть много примеров с правильными ответами — тогда модель строится **по данным**, а не по теории.

Возьмем семейство функций, решающих задачу и найти функцию, лучше всего решающих задачу

**Задача ML** - минимизации функционала ошибки по множеству моделей

**Когда ML НЕ нужен:** если зависимость и так точно выводится (сила = масса × ускорение, сортировка массива) — незачем городить модель.

**Когда ML уместен (3 признака):**
- Нельзя вывести формулу из знаний о мире
- Зависимость сложная, вручную не подобрать
- Есть достаточно примеров с известными ответами

Также ML полезен, когда:
- Зависимость понятна человеку, но применять её вручную долго/дорого (перевод текста)
- Формального алгоритма нет вообще, но люди справляются на опыте (плавка стали, игра в го → AlphaGo)

## Базовые термины

| Термин | Значение | Обозначение |
|---|---|---|
| Модель | Функция, отображающая объект в целевую переменную | $a: X \to Y$ |
| Объект | То, для чего мы делаем прогноз | $x$ |
| Пространство объектов **X** | всё множество возможных объектов (все иностранные тексты) |
| Пространство ответов **Y** | множество значений целевой переменной(все переводы текстов) |
| Целевая переменная | то, что предсказываем | $y$ |
| Обучающая выборка | набор пар (объект, правильный ответ) |$X={(x1,y1),...,(x\ell,y\ell)}$|
| Признак (feature) | некоторая характеристика объекта | $x_i$ |
| Признаковое описание | вектор всех признаков объекта | $x=(x_1, \dots, x_d)$ |
| Feature engineering | разработка признаков — один из самых важных и сложных этапов |
| Функция потерь | ошибка одного отдельного предсказания | $L(y,z)$  |
| Функционал ошибки(на вход можель и выборка) | мера того, насколько плох алгоритм; то, что минимизируем | $Q(a,X) = \frac{1}{\ell}\sum^{\ell}_{i=1}L(y_i,a(x_i))$ |
| Обучение | процесс поиска наилучших параметров модели (минимизация функционала) |
## Виды признаков
1. **Бинарные** – принимают два значения.
2. **Числовые** – вещественные числа.
3. **Категориальные (номинальные)** – неупорядоченное множество значений(жанр музыки).
4. **Порядковые** – частично упорядоченное множество (можно сравнивать, но арифметика неприменима, например, тип музыкального альбома).
5. **Set-valued(множественнозначные)** – набор категорий.
6. **Со сложной структурой** – звук, изображение и т.п.


## Множество ответов определяет тип задач(функцию ошибок, множество моделей)

### Обучение с учителем(supervised)
Обучающая выборка содержит правильные ответы.

- **Регрессия** – ответ – вещественное число (например, спрос на товар, продолжительность поездки).
- **Бинарная классификация** – ответ – 0 или 1.
- **Многоклассовая классификация (multiclass)** – конечное множество ответов, принадлежность к одному из классов.
- **Многоклассовая классификация с пересекающимися классами (multilabel)** – принадлежность к нескольким классам одновременно.
- **Ранжирование** – ответ – конечное упорядоченное множество.


### Обучение без учителя(unsupervised)
Обучающая выборка набор объектов без правильного ответа

- **Кластеризация** – группировка объектов без целевой переменной.
- **Понижение размерности** – уменьшение числа признаков у каждого объекта.

## Как выбирается модель

1. Создаем матрицу «объекты-признаки» `X` (строки — объекты, столбцы — признаки)
2. Фиксируем функционал ошибки, например MSE: `Q = (1/ℓ)Σ(a(xi)-yi)²`
3. Фиксируем семейство алгоритмов A (напр. линейные модели)
4. Обучение = минимизация функционала по параметрам, часто градиентными методами (движение в сторону антиградиента)
   - выпуклый функционал → находим глобальный минимум
   - невыпуклый → только гарантия сходимости к локальному

Важно: **функционал ошибки должен отражать реальные требования задачи**, а не просто быть удобным математически (дифференцируемым и т.п.) — если метрика выбрана неудачно, всё дальнейшее бессмысленно.

## Предобработка данных

- **Нормировка** — привести признаки к одной шкале (вычесть среднее, поделить на дисперсию) — критично для линейных моделей
- **Выбросы** — некорректные объекты (ошибки сбора/расчёта признаков), портят модель
- **Шумовые признаки** — не связаны с целевой переменной, только мешают


## Метрики качества модели

1. **Бизнес-метрики** – например, будущий доход сервиса. Их трудно измерить в моменте, они зависят от совокупности всех усилий, не только машинного обучения.

2. **Онлайн (online) метрики** – характеристики работающей системы, по которым мы надеемся оценить влияние на бизнес-метрики.
   Примеры:
   - Медианная длина сессии в онлайн-игре (предполагаем, что долгая сессия — признак довольного пользователя).
   - Среднее количество бананов на полках во всех магазинах в конце дня.

3. **Оценка специально нанятыми людьми (асессорами)** – например, качество машинного перевода или релевантность выдачи в поисковой системе.

4. **Офлайн (offline) метрики** – измеряются до введения модели в эксплуатацию по историческим данным.
   В задачах предсказания таргета обычно оценивают отклонение предсказаний модели от истинных значений:
   - точность (доля верно угаданных значений),
   - среднеквадратичное отклонение.

## Этапы решения задачи ML (чек-лист)

1. Постановка задачи
2. Выделение признаков
3. Формирование выборки
4. Выбор метрики качества
5. Предобработка данных
6. Построение модели
7. Оценивание качества модели

## Функция потерь и функционал ошибки

- **Функция потерь** – положительное число, описывающее правильность ответа на одном объекте.
- **Функционал ошибки** – функция, принимающая модель и усредняющая потери по всем объектам обучающей выборки.
