# Лекция 8. Бэггинг, случайные леса, разложение bias-variance — кратко

## Идея

Деревья по отдельности неустойчивы (малое изменение данных сильно меняет дерево), но при объединении в композицию (усреднении многих деревьев) дают отличный результат. **Бэггинг** — независимо строит много моделей и усредняет ответы. (Бустинг — другой подход, строит модели последовательно; будет дальше.)

## Бутстрап и наивная интуиция усреднения

**Бутстрап** — генерация подвыборки: берём `ℓ` объектов из выборки **с возвращением** (будут повторы, некоторые объекты не попадут вообще).

Если обучить N моделей на N бутстреп-подвыборках и ответы **несмещены и некоррелированы**, то усреднение ответов уменьшает средний квадрат ошибки в **N раз**:
```
E_N = (1/N)·E_1
```
На практике предположение о некоррелированности не выполняется (модели похожи, т.к. обучены на похожих данных) → выигрыш меньше. Отсюда мотивация специально понижать корреляцию между базовыми моделями (→ случайный лес).

## Bias-Variance разложение (для MSE)

Ошибка метода обучения `µ` (усреднённая по всем возможным обучающим выборкам) раскладывается на 3 части:
```
L(µ) = шум + смещение² + разброс
```
- **Шум** — `E[(y-E[y|x])²]` — неустранимая ошибка данных, ошибка идеального алгоритма (меньше нельзя, никаким методом)
- **Смещение (bias)** — `E[(E_X[µ(X)] - E[y|x])²]` — насколько средний ответ метода (по всем возможным обучающим выборкам) отличается от истинного оптимального ответа
- **Разброс (variance)** — `E[E_X[(µ(X)-E_X[µ(X)])²]]` — насколько сильно меняется ответ модели в зависимости от конкретной обучающей выборки

**Интуиция:**
- Простые семейства (линейные модели) — **большое смещение, малый разброс**: стабильны, но систематически не дотягивают до сложной истинной зависимости
- Сложные семейства (глубокие деревья) — **малое смещение, большой разброс**: могут приблизить что угодно, но сильно "дёргаются" от выборки к выборке

Разложение доказано строго для MSE, но качественно верно и для других функций потерь (в т.ч. для ошибки классификации).

## Как бэггинг влияет на bias и variance

- **Смещение композиции = смещению одного базового алгоритма** — бэггинг **не улучшает и не ухудшает** bias
- **Разброс уменьшается**, но насколько — зависит от корреляции между базовыми алгоритмами:
  ```
  Var(композиции) = (1/N)·Var(одного алгоритма) + ((N-1)/N)·Cov(между алгоритмами)
  ```
  Если модели некоррелированы — разброс падает в N раз. Если сильно коррелированы — выигрыш почти нулевой.

**Вывод:** бэггинг выгоден для баз-алгоритмов с **малым смещением и большим разбросом** (глубокие, переобученные деревья) — именно их бэггинг "успокаивает", усредняя дисперсию, при этом малое смещение сохраняется.

## Случайные леса (Random Forest)

Бэггинг над решающими деревьями + дополнительная рандомизация, чтобы **понизить корреляцию** между деревьями (чем меньше корреляция — тем сильнее падает разброс):

**Алгоритм:**
1. Для каждого из N деревьев: бутстреп-подвыборка объектов
2. В каждой вершине дерева: разбиение ищется не по всем `d` признакам, а по случайному подмножеству из `m` признаков
3. Итог: `a_N(x) = (1/N)Σ bₙ(x)`

**Рекомендуемые параметры:**
- Классификация: `m ≈ √d`, дерево строится до листьев из **1 объекта**
- Регрессия: `m ≈ d/3`, дерево строится до листьев из **5 объектов**

Случайный лес — один из сильнейших и наиболее универсальных методов; часто чуть уступает градиентному бустингу, но гораздо проще в реализации и настройке.

### Out-of-Bag (OOB) оценка
Каждое дерево обучено на своей подвыборке — объекты, не попавшие в неё, автоматически являются "контрольными" для этого дерева. Можно для каждого объекта усреднить ответы только тех деревьев, которые его не видели при обучении, и получить оценку качества **без отдельной отложенной выборки**:
```
OOB = Σᵢ L(yᵢ, среднее по деревьям, не видевшим xᵢ)
```
При росте числа деревьев OOB-оценка приближается к leave-one-out CV, но считается гораздо быстрее.

### Связь со метрическими методами
Ответ дерева на объекте `x` — это среднее ответов обучающих объектов, попавших с ним в один лист. Значит, ответ всего леса:
```
a_N(x) = Σᵢ w(x,xᵢ)·yᵢ
```
где `w(x,xᵢ)` — доля деревьев, где `x` и `xᵢ` оказались в одном листе — то есть некая **мера схожести** объектов. Случайный лес неявно вводит метрику на объектах — тот же принцип, на котором строится метод k ближайших соседей (будет позже).

**Практический трюк:** номер листа `Tₙ(x)`, в который попал объект — сам по себе полезный признак. Можно обучить небольшой лес/бустинг, а затем добавить `T₁(x),...,Tₙ(x)` как новые категориальные признаки для другой модели — они несут нелинейную информацию о структуре данных.
