# Лекция 7. Решающие деревья

## Зачем деревья

Линейные модели быстрые, простые, легко регуляризуются, но восстанавливают **только линейные** зависимости. Деревья умеют находить нелинейные зависимости произвольной сложности и хорошо описывают процесс принятия решений (как последовательность вопросов типа "если возраст < 18 → отказ, иначе...").

**Минус деревьев:** дискретная структура → нельзя дифференцировать и учить градиентным спуском; число параметров не фиксировано → все алгоритмы построения дерева **жадные и эвристические** (поиск оптимального минимального дерева — NP-полная задача). Сегодня одиночные деревья используют редко — зато они отлично работают как база для композиций (случайный лес, бустинг).

## Устройство дерева

- Внутренняя вершина `v` → предикат `βᵥ: X→{0,1}`
- Лист `v` → прогноз `cᵥ` (класс, число, или вектор вероятностей)
- Обычно используют **одномерные пороговые предикаты**: `β(x;j,t) = [xⱼ < t]`
  (многомерные — линейные/метрические — существуют, но усиливают переобучение, используются редко)

## Жадный алгоритм построения

1. Взять всю выборку, найти наилучшее разбиение `(j,t)` на `R1={x|xⱼ<t}` и `R2={x|xⱼ≥t}` по критерию качества `Q`
2. Создать вершину с предикатом `[xⱼ<t]`, рекурсивно повторить для обеих частей
3. Остановиться по критерию останова → объявить лист, назначить прогноз (класс большинства / среднее / медиана и т.д. — в зависимости от функционала)

Метод построения дерева определяется 5 вещами: **виды предикатов, функционал качества, критерий останова, обработка пропусков, метод стрижки**.

## Критерии информативности (impurity)

Общая форма прироста качества при разбиении вершины `Rm` на `Rℓ, Rr`:
```
Q(Rm,j,t) = H(Rm) - (|Rℓ|/|Rm|)H(Rℓ) - (|Rr|/|Rm|)H(Rr)   → максимизировать
```
`H(R)` — критерий информативности: насколько хорошо целевая переменная в `R` предсказывается одной константой:
```
H(R) = min_c (1/|R|) Σ L(yᵢ,c)
```

### Для регрессии (L = квадрат отклонения)
Минимум достигается на среднем → `H(R)` = **дисперсия** целевой переменной в вершине:
```
H(R) = (1/|R|) Σ(yᵢ - ȳ)²
```
(Если L = модуль отклонения → получаем среднее абсолютное отклонение от **медианы**.)

### Для классификации
`pₖ` — доля объектов класса k в вершине.

| Критерий | Формула | Смысл |
|---|---|---|
| **Ошибка классификации** | `H(R) = 1 - p_k*` | грубый — учитывает только долю самого частого класса |
| **Критерий Джини** | `H(R) = Σ pₖ(1-pₖ)` | из критерия Бриера (аналог MSE для вероятностей), оптимум на `cₖ=pₖ` |
| **Энтропия** | `H(R) = -Σ pₖ·log(pₖ)` | из log-loss, тоже оптимум на `cₖ=pₖ`; минимум (=0) при вырожденном распределении, максимум — при равномерном |

Джини и энтропия — более информативные критерии, чем простая ошибка классификации, т.к. учитывают распределение по всем классам, а не только по самому частому.

## Критерии останова

- Максимальная глубина дерева
- Минимальное число объектов в листе
- Максимальное число листьев
- Все объекты в листе — один класс
- Улучшение критерия при разбиении меньше порога s%

Подбор — трудозатратен, требует кросс-валидации.

## Стрижка (pruning)

Альтернатива раннему останову: сначала строим **переобученное** дерево (до листьев из одного объекта), потом упрощаем.

**Cost-complexity pruning:** штрафуем за размер дерева
```
Rα(T) = R(T) + α|T|
```
`α` — параметр баланса качество/сложность. Существует последовательность вложенных деревьев `Tk ⊂ ... ⊂ T0`, каждое оптимально для своего диапазона `α`; лучшее выбирают по отложенной выборке/CV.

*(На практике стрижка сейчас используется редко — деревья либо специально переобучают в композициях типа случайного леса, либо ограничивают малой глубиной в бустинге.)*

## Обработка пропущенных значений

Дерево — одна из немногих моделей, умеющих работать с пропусками "из коробки":
- При выборе разбиения — считать критерий качества только по объектам с известным значением признака, с поправкой на долю пропущенных
- Объекты с пропуском отправлять **в оба** поддерева с весами, пропорциональными размерам поддеревьев (и на обучении, и на инференсе — прогноз усредняется с этими весами)
- Альтернатива: **суррогатные предикаты** — если основной признак пропущен, использовать другой признак, дающий похожее разбиение
- Простой практический вариант: заменить пропуски на 0 или на число, заведомо большее любого значения признака (тогда все объекты с пропуском уйдут в одно поддерево)

## Категориальные признаки в деревьях

- **Multi-way split:** сделать столько поддеревьев, сколько значений у признака — просто, но может дать дерево с огромным числом листьев
- **Разбиение на 2 группы значений:** признак с `q` значениями → перебор `2^(q-1)-1` вариантов дорог, НО для бинарной классификации и регрессии есть точный трюк без полного перебора: **упорядочить** значения признака по доле положительного класса (для классификации) или по среднему ответу (для регрессии), затем искать разбиение как для обычного вещественного признака — оптимум совпадает с полным перебором (при критерии Джини/энтропии/MSE)

## Популярные алгоритмы построения деревьев

| Алгоритм | Критерий | Стрижка | Пропуски |
|---|---|---|---|
| **ID3** | энтропия | нет (растёт до чистых листьев) | — |
| **C4.5** | Gain Ratio (нормированная энтропия) | Error-Based Pruning | игнор + перенос в оба поддерева с весами |
| **CART** | Джини | Cost-Complexity Pruning | суррогатные предикаты |

## Связь дерева и линейной модели

Дерево разбивает пространство признаков на непересекающиеся области `J₁...Jₙ`, в каждой выдаёт константу `wⱼ`:
```
a(x) = Σ wⱼ·[x ∈ Jⱼ]
```
Это буквально **линейная модель** над новыми бинарными признаками `[x∈Jⱼ]`! Дерево, по сути, жадно подбирает нелинейное преобразование признаков, а затем строит поверх него линейную модель — идея, которая потом повторится во многих других нелинейных методах ML.
