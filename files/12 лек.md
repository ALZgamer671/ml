# Лекция 12. Матричные разложения и рекомендательные системы

## 1. Метод главных компонент (PCA)

**Задача:** снизить размерность признакового пространства с `D` до `d`, найдя новые признаки как линейные комбинации старых, минимизируя потерю информации (при квадратичной ошибке — получаем PCA).

Ищем **главные компоненты** `u1,...,uD ∈ Rᴰ` такие, что:
1. Ортогональны: `⟨uᵢ,uⱼ⟩=0`
2. Нормированы: `‖uᵢ‖²=1`
3. Проекция выборки на них даёт **максимальную дисперсию** среди всех возможных наборов из `d` компонент

Дисперсия проекции = сохранённая "информация" → хотим максимизировать.

**Решение через множители Лагранжа:** первая компонента `u1` — это **собственный вектор ковариационной матрицы `XᵀX`, соответствующий наибольшему собственному значению**. Остальные компоненты — следующие по величине собственные значения (с условием ортогональности предыдущим).

**Применение:** проекция выборки на первые `d` компонент — `XU_d`. Для новых (тестовых) данных: `Z' = X'U_d`.

**Альтернативные эквивалентные постановки:**
- Матричное разложение: найти `Z` и `U`, минимизируя `‖X - ZUᵀ‖²` — решение те же собственные векторы
- Минимизация расстояния от объектов до их проекций на подпространство — эквивалентно максимизации дисперсии проекций

## 2. Рекомендательные системы

**Задача:** по известным оценкам `rᵤᵢ` (заинтересованность пользователя u в товаре i) для каждого пользователя подобрать k наиболее релевантных товаров.

### Коллаборативная фильтрация — Memory-based

Похожесть пользователей `u,v` через **корреляцию Пирсона** по общим товарам `Iᵤᵥ`:
```
w_uv = Σ(r_ui-r̄_u)(r_vi-r̄_v) / √(Σ(r_ui-r̄_u)²·Σ(r_vi-r̄_v)²)
```
Аналогично считается похожесть товаров `wᵢⱼ` (по общим пользователям `Uᵢⱼ`).

**User-based CF:** найти похожих пользователей `U(u0)={v|w_{u0,v}>α}`, рекомендовать товары, часто встречающиеся у них. Минус: не работает для "нетипичного" пользователя без похожих соседей.

**Item-based CF:** найти товары, похожие на уже интересовавшие пользователя, рекомендовать их. Работает даже для нетипичного пользователя.

### Модели со скрытыми переменными (Latent Factor Models)

Проблема memory-based подходов: нужно хранить огромную разреженную матрицу `R`, методы эвристичны.

**Идея:** представить каждого пользователя `u` и товар `i` векторами `pᵤ, qᵢ ∈ Rᵈ` ("эмбеддинги" — категории интересов, необязательно интерпретируемые явно). Рейтинг приближаем скалярным произведением:
```
r_ui ≈ p̄_u + r̄_i + ⟨pᵤ,qᵢ⟩
```
Функционал (регуляризованный):
```
Σ(r_ui - r̄_u - r̄_i - ⟨pᵤ,qᵢ⟩)² + λΣ‖pᵤ‖² + µΣ‖qᵢ‖² → min
```
Это по сути **низкоранговое матричное разложение**: `‖R' - PᵀQ‖² → min`. Модель называется **Latent Factor Model (LFM)**, была ключевым методом в Netflix Prize.

**Способы обучения:**
- **SGD:** случайно берём пару `(u,i)`, делаем шаг градиента по `pᵤ` и `qᵢ`
- **ALS (Alternating Least Squares):** функционал невыпуклый по `(P,Q)` совместно, но выпуклый при фиксации одной из матриц — оптимальное значение для другой считается аналитически (с обращением матрицы)
- **HALS:** упрощение ALS — фиксируем всё, кроме одной строки `P` или `Q`, находим её оптимум без обращения матрицы

### Учёт неявной информации (implicit feedback)

Явные оценки (рейтинг, лайк) редки, неявных сигналов (просмотры, клики) намного больше, но им нельзя полностью доверять.

**Implicit ALS (iALS):** вводим бинарный индикатор интереса `sᵤᵢ=[есть оценка]` и вес уверенности `cᵤᵢ=1+α·rᵤᵢ` — чем выше явный рейтинг, тем больше уверенность в интересе:
```
Σ c_ui(s_ui - s̄_u - s̄_i - ⟨pᵤ,qᵢ⟩)² + λΣ‖pᵤ‖² + µΣ‖qᵢ‖² → min
```

### Контентные модели

В отличие от коллаборативной фильтрации, используют не только историю оценок, а **свойства** пользователей и товаров (текстовые описания, категории, профиль). Формируют признаковое описание пары (пользователь, товар) и предсказывают рейтинг обычной моделью (линейной, деревьями и т.д.).
