## 🤖 Этап 3 — Machine Learning и Deep Learning

Ядро этапа. Здесь появляются проекты и понимание «как это работает изнутри».

### 📌 Задачи этапа
1. **Классический ML:**
   - Линейные модели: Linear/Logistic Regression, регуляризация (L1/L2).
   - Деревья: Decision Tree, Random Forest, **Gradient Boosting (XGBoost, LightGBM, CatBoost)**.
   - Кластеризация: K-Means, DBSCAN.
   - Метрики: Accuracy, Precision/Recall, F1, ROC-AUC, LogLoss.
   - Разложение ошибки: bias–variance, кросс-валидация.
2. **Глубокое обучение:**
   - Нейросети «с нуля» на NumPy (полносвязная сеть + backprop). 
   - **PyTorch** — основной фреймворк (в Яндексе используется активно).
   - CNN (свёрточные сети) для картинок, RNN/Transformer для текста.
   - Механизм attention и трансформеры (важно! YandexGPT — это трансформеры).
3. **Дополнительно (бонус для набора очков):**
   - Эмбеддинги, рекомендательные системы, обучение с подкреплением (RL).
